# DDJ-SB3 для rekordbox

MIDI-маппинг и небольшой мост для macOS, с которыми Pioneer DJ DDJ-SB3, контроллер для Serato, работает в rekordbox 7, включая джоги.

```
DDJ-SB3 (USB MIDI) ──► sb3bridge ──► virtual port "DDJ-SB2" ──► rekordbox
        ◄── LEDs ──────────┘ ◄──────────── LED feedback ◄──────────┘
```

rekordbox принимает пользовательский MIDI-маппинг для любого контроллера, но молча игнорирует строки джогов (`JogRotate`, `JogTouch`) у устройств, которых нет в его списке поддерживаемых. DDJ-SB3 в этом списке нет, DDJ-SB2 есть, а коды джогов у них одинаковые. `sb3bridge` публикует SB3 под именем `DDJ-SB2` и пересылает сообщения в обе стороны, поэтому rekordbox считает джоги настоящими.

Проверено 25 ноября 2026 на macOS 26.2 и rekordbox 7.2.19, Apple Silicon.

## Что нужно

| Что | Версия | Зачем |
| --- | --- | --- |
| macOS | проверено на 26.2 | мост использует CoreMIDI и CoreAudio |
| Xcode Command Line Tools | Swift 5.9 или новее (проверено на 6.3) | собирает мост и утилиты; ставится командой `xcode-select --install` |
| rekordbox | 7 (проверено на 7.2.19) | формат маппинга и имена функций взяты из его встроенных маппингов |
| Python | 3.9 или новее | только чтобы пересобрать CSV-маппинги |

Драйвер не нужен: macOS видит SB3 как стандартную USB-звуковую карту на 4 выхода (1–2 мастер, 3–4 наушники).

> [!NOTE]
> Доступен ли MIDI-маппинг на бесплатном тарифе rekordbox, не проверялось. Если кнопка MIDI в rekordbox неактивна, причина в тарифе.

## Быстрый старт

1. Соберите всё:

   ```bash
   git clone https://github.com/om1ji/ddj-sb3-rekordbox.git
   cd ddj-sb3-rekordbox
   make
   make install    # по желанию: копирует мост в /Applications/sb3bridge
   ```

2. Подключите SB3 и запустите мост. Окно Терминала не закрывайте:

   ```bash
   adapter/sb3bridge
   ```

   Мост напишет `DDJ-SB3 подключён` и `виртуальный порт «DDJ-SB2» готов`.

3. Запустите rekordbox. В **Preferences → Audio** выберите `DDJ-SB3 Audio Out`, назначьте выход Master на каналы 1 & 2, а Headphones на 3 & 4.

4. Перейдите в режим **PERFORMANCE**, нажмите **MIDI** справа вверху, выберите в списке устройств **DDJ-SB2**, нажмите **IMPORT** и укажите [`mappings/DDJ-SB2.midi.csv`](mappings/DDJ-SB2.midi.csv).

5. В том же окне MIDI выберите **DDJ-SB3** и удалите все его назначения, если они есть. Иначе каждое нажатие будет доходить до rekordbox дважды, подробнее в разделе [Если что-то не работает](#если-что-то-не-работает).

## Каждый день

1. Подключите SB3.
2. Запустите `sb3bridge`, только в одном окне.
3. Запустите rekordbox.

Порядок важен: rekordbox подхватывает только те MIDI-порты, которые уже есть в момент его запуска. Перезапустили мост, перезапустите и rekordbox.

Мост останавливается по `Ctrl+C` или закрытием окна.

## Раскладка

Режимы пэдов SB3 переключает сам: в каждом режиме пэды шлют свой блок нот, и каждому режиму соответствует своя функция rekordbox. У четырёх режимов Serato аналога в rekordbox нет, им назначен ближайший режим rekordbox.

| Контрол SB3 | rekordbox |
| --- | --- |
| Пэды HOT CUE | Hot Cue 1–8, `SHIFT` + пэд удаляет |
| `SHIFT` + HOT CUE: BEAT JUMP | Beat Jump; `SHIFT` + пэды 7/8 меняют размер прыжка |
| FX FADE | Pad FX 1 (`SHIFT` + пэд: слоты 9–16) |
| `SHIFT` + FX FADE: ROLL | Beat Loop |
| PAD SCRATCH | Pad FX 2 (`SHIFT` + пэд: слоты 9–16) |
| `SHIFT` + PAD SCRATCH: SLICER | Slicer |
| SAMPLER | Sampler, `SHIFT` + пэд останавливает слот |
| `SHIFT` + SAMPLER: TRANS | Key Shift; `SHIFT` + пэды 7/8 меняют диапазон |
| Джог, верх | Pitch bend; при включённом VINYL скретч |
| Джог, боковое кольцо | Pitch bend |
| `SHIFT` + джог | Быстрая перемотка |
| AUTO LOOP, 1/2X, 2X | Луп на 4 бита, половина, удвоение; с `SHIFT`: Reloop/Exit, Loop In, Loop Out |
| VINYL / `SHIFT` + VINYL | Режим Vinyl / Slip |
| KEY LOCK / `SHIFT` + KEY LOCK | Master Tempo / диапазон темпа |
| SYNC / `SHIFT` + SYNC | Sync / Master |
| FILTER | Sound Color FX канала |
| Кнопки FX 1–3 | Включение слотов Beat FX; с `SHIFT`: выбор эффекта |
| Ручка FX / `SHIFT` + ручка FX | Глубина слота 1 / доля такта |
| CUE (наушники) / `SHIFT` + CUE | Канал в наушники / Tap BPM |
| MASTER (наушники) | Мастер в наушники, подробнее ниже |
| `SHIFT` + MASTER | Выравнивает состояние MASTER, обрабатывает только мост |
| `SHIFT` + LOAD | Сортировка по BPM и исполнителю |

## Как это работает

### Зачем виртуальный «DDJ-SB2»

Джоги rekordbox оставляет только контроллерам, которые поддерживает сам. Маппинг для SB3 импортируется без ошибок, все кнопки работают, а строки джогов не делают ничего. На [форуме Pioneer DJ](https://community.pioneerdj.com/hc/en-us/community/posts/22979790097945-MIDI-Learn-Jog-wheel) на этот вопрос отвечают, что джоги контроллеров не от Pioneer назначить нельзя; SB3 сделан Pioneer, но rekordbox его не поддерживает.

DDJ-SB2 поддерживается, и его сообщения джогов байт в байт совпадают с SB3 (`B0n 22`, `B0n 23`, `9n 36`, `B0n 21`). Виртуального порта с таким именем достаточно, чтобы rekordbox начал принимать данные джогов. Тот же маппинг затем импортируется для устройства `DDJ-SB2`.

Платные функции это не открывает: hardware unlock rekordbox проверяет по USB, а не по имени MIDI-порта.

### Режим VINYL

SB3 всегда шлёт вращение джога как `B0n 23` (pitch bend), что бы ни показывала кнопка VINYL. Прошивка DDJ-SB2 переключается на `B0n 22` (скретч), когда программа зажигает её светодиод VINYL. Мост делает то же самое: следит за сообщением подсветки VINYL от rekordbox (`9n 17`) и, пока оно включено, переписывает `B0n 23` в `B0n 22` для этой деки.

### MASTER в наушниках

Светодиод MASTER SB3 переключает сам, при каждом нажатии, а мастер в каналы наушников подмешивает rekordbox (`MasterCue`). Эти два состояния могут разойтись на одно нажатие, и кнопка начинает работать наоборот. После каждого нажатия rekordbox сообщает своё состояние (`96 5B 7F` или `96 5B 00`); если оно не совпадает со светодиодом, мост досылает rekordbox ещё одно нажатие. При запуске мост считает, что светодиод не горит. `SHIFT` + MASTER меняет это предположение на обратное, на случай если мост запустили при уже горящем MASTER, и в rekordbox не передаётся.

### Только один экземпляр

Второй мост создал бы второй порт `DDJ-SB2`, и rekordbox получал бы каждое сообщение дважды. При запуске мост ищет уже существующий источник `DDJ-SB2` и, если находит, завершается.

### Откуда MIDI-коды

Коды SB3 взяты из открытого маппинга Mixxx (`res/controllers/Pioneer-DDJ-SB3.midi.xml` в [mixxxdj/mixxx](https://github.com/mixxxdj/mixxx)), который составлен по официальной таблице MIDI-сообщений Pioneer. Имена функций и формат CSV взяты из встроенных маппингов rekordbox 7 (`DDJ-SB2.midi.csv`, `DDJ-400.midi.csv`). Ноты пэдов в режимах FX FADE (`0x10`), PAD SCRATCH (`0x20`) и TRANS (`0x70`) выведены из раскладки подсветки и потом проверены на контроллере.

## Как поменять маппинг

Отредактируйте [`gen_mapping.py`](gen_mapping.py) и пересоберите маппинги:

```bash
make mappings
```

Затем снова импортируйте `mappings/DDJ-SB2.midi.csv` в окне MIDI rekordbox.

В каждой строке CSV 15 колонок: функция rekordbox, подпись контрола, тип, входной код, четыре колонки дек, выходной код, ещё четыре колонки дек, опции, комментарий. Колонка деки — это смещение MIDI-канала: `0`–`3` для дек, `7`–`10` для пэдов. Вход `900B` с декой `1` означает `91 0B` на проводе. Генератор не пропускает запятые внутри полей: кавычек rekordbox не понимает, и одна запятая сдвигает все колонки после неё.

## Утилиты для отладки

Все утилиты обращаются к устройству по имени, поэтому работают и при запущенных rekordbox и мосте.

```bash
tools/midimon 30 ddj                    # 30 с печатает все MIDI-сообщения с портов, где в имени есть «ddj»
tools/midisend "90 17 7F"               # шлёт сырые байты на DDJ-SB3
tools/ledscan                           # бинарный поиск ноты, которая зажигает светодиод (спрашивает y/n)
tools/tonetest "DDJ-SB3 Audio Out" 3 1  # 440 Гц на 3 с на выходы 1-2 (мастер)
tools/tonetest "DDJ-SB3 Audio Out" 3 2  # то же на выходы 3-4 (наушники)
```

`midimon` показывает и SB3, и порт моста `DDJ-SB2`. По этому видно, потерялось ли сообщение по дороге или его проигнорировал rekordbox. `adapter/sb3bridge -v` дополнительно пишет, что rekordbox отправляет обратно контроллеру.

`tonetest` понадобился потому, что `afplay` играет на системный выход по умолчанию, а это не обязательно SB3, а `say -a '?'` SB3 вообще не показывает.

## Если что-то не работает

| Симптом | Причина | Что делать |
| --- | --- | --- |
| Джоги не отвечают, кнопки работают | мост не запущен или rekordbox открыли раньше него | запустить `sb3bridge`, потом перезапустить rekordbox |
| VINYL, CUE, KEY LOCK срабатывают через раз, мигают или не реагируют | rekordbox получает каждое нажатие дважды: от моста и напрямую от SB3 | удалить в окне MIDI все назначения `DDJ-SB3`; см. ниже |
| То же самое сразу после запуска моста во втором окне | два моста, два порта `DDJ-SB2` | закрыть один; текущая версия второй раз не запускается |
| `порт «DDJ-SB2» уже есть: мост уже запущен в другом окне. Выход.` | мост уже работает | пользоваться запущенным |
| MASTER в наушниках работает наоборот | мост запустили при горящем MASTER | один раз нажать `SHIFT` + MASTER |
| Нет звука, `afplay` пишет `AudioQueueStart failed ('what')` | карту держит rekordbox или выход по умолчанию не SB3 | проверять через `tools/tonetest` |
| Звук пропадает, ошибки то есть, то нет | SB3 питается от USB, вероятная причина — цепочка хабов | подключить напрямую или через хаб с отдельным питанием |

rekordbox хранит собственную копию пользовательских маппингов и может заново создать `~/Library/Application Support/Pioneer/rekordbox6/MidiMappings/DDJ-SB3.midi.csv` после того, как его удалили или переименовали. Вместе с ним возвращается и двойное срабатывание. Маппинг без назначений — это файл из одной строки, именно его rekordbox пишет для устройства, у которого ничего не назначено:

```bash
# при закрытом rekordbox
printf '@file,1,DDJ-SB3\r\n' > ~/Library/Application\ Support/Pioneer/rekordbox6/MidiMappings/DDJ-SB3.midi.csv
```

## Ограничения

- **Только macOS.** Мост построен на виртуальных портах CoreMIDI.
- **Мост нужно запускать вручную**, до rekordbox. Его можно оформить как LaunchAgent, но репозиторий этого за вас не делает.
- **Четыре режима пэдов отличаются от Serato.** FX FADE, PAD SCRATCH, ROLL и TRANS запускают ближайшие режимы rekordbox. Привычные движения сохраняются, результат нажатия другой.
- **Ручки уровня мастера и наушников** (`B6 08`, `B6 0D`) не назначены ни на какую функцию. Применяет ли их SB3 аппаратно, не проверялось.
- **Прерывистый шум в наушниках**, похожий на передачу данных, был слышен при тестах и не устранён. Обычные подозреваемые — питание по USB и петля заземления: попробуйте работу от батареи вместо зарядки, прямое USB-подключение и паузу, чтобы понять, связан ли шум с индикаторами уровня.
- **rekordbox может измениться.** Ограничение на джоги и формат CSV — недокументированное поведение rekordbox 7.2.

Проект не связан с Pioneer DJ и AlphaTheta.
